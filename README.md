# 东方归言录国服 · 关服倒计时网页

> 东方归言录国服纯静态关服倒计时网页，用于记录与告别。

本项目为非官方粉丝作品，与东方归言录（Touhou LostWord）的开发商、发行商及东方 Project 权利方无任何关联；页面不包含任何游戏美术、音频等素材，相关名称与商标归各自权利人所有。代码部分以 MIT 协议开源。

---

## 项目简介

| 项目 | 说明 |
|---|---|
| 名称 | 东方归言录国服关服倒计时 |
| 技术栈 | 原生 HTML + CSS + JavaScript |
| 类型 | 纯静态页，无构建、无运行时依赖 |
| 浏览器要求 | 支持 ES2017 与 CSS Grid 的现代浏览器（约 2018 年后） |
| 数据基准 | 停服时间 2027-02-03 14:00（UTC+08:00） |

本项目以 2027-02-03 为基准时间进行东方归言录国服关服倒计时。页面大量依赖 JavaScript，使用时请开启浏览器 JavaScript 功能。

---

## 功能

- 秒级倒计时与运营周期进度条
- 编年史时间轴，随当前时间点亮节点、推进光束
- Canvas 绘制的光束背景，支持 `prefers-reduced-motion` 降级
- 停服瞬间的天数灰化、光点熄灭、背景变灰过渡，以及终章文案交叉淡入
- 纯静态单页，双击 `index.html` 即可打开，无需服务器

---

## 快速开始

无需安装依赖，直接打开 `index.html` 即可。

也可以使用任意静态服务器预览：

```bash
npx serve .
```

> 页面通过相对路径引用 `css/`、`js/`，部署时请保持目录结构不变。

## 时间与数据

- 开服时间、停服时间与编年史集中在 [js/countdown.js](js/countdown.js) 顶部的 `DATA` 中，页面上的日期文案均由脚本派生，修改数据只需改这一处
- 起止时间取自编年史中 `kind: "start"` 与 `kind: "deadline"` 的条目
- `TEST_END_DELAY` 为测试开关：`0` 表示使用正式停服时间；设为 `N` 可在页面加载后 N 秒模拟停服，便于检查停服瞬间的动效，测完请改回 `0`

页面中的停服时间与编年史为硬编码数据。如与官方公告不一致，以官方公告为准，欢迎提交 Issue 或 PR 勘误。

---

## 兼容性

- 依赖 `String.prototype.padStart`、CSS Grid、`Intl.DateTimeFormat.formatToParts`，2018 年后的主流浏览器均可运行
- 完整的颜色过渡需要 `@property`：Chrome/Edge 85+、Safari 16.4+、Firefox 128+；更早的版本中，依赖 CSS 变量的局部颜色会瞬时切换，功能与布局不受影响
- 启用 `prefers-reduced-motion` 时，Canvas 与界面过渡会降级为静止/瞬时状态
- 由于难以覆盖全部环境，本项目无法保证在 2019 年以前的浏览器版本和部分特殊内核浏览器中正常显示
